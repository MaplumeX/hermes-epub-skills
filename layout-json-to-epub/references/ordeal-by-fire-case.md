## 本案例新要点
- **本版没有页码式脚注区**：页底注全是 `*`/`**` 译者注 + 极少数 ① 编者注（上册 45 条 / 下册 19 条）；正文数字上标是**尾注**，文本在书末「附注」（英文文献引证），上册里完全没有 → 必须等下册 + 附注文件到齐才能建链接。
- **星号 OCR 变体**（下册实测）：`- ` `—` `法` 开头都是 `*`；`* *` = `**`。无标记块 = 上一条续行（换行续页）。
- **附注解析**（`extract_down.py:parse_notes`）：`ref_text`/`text` 块按 `^\d{1,3}[.、]` 分条，无序号 → 续上一条；**块内可能粘着下一条**（`\n(?=\d{1,3}[.、])` 再分）；跨页/跨文件续行同样处理。续册文件的**首个块可能是上一册最后一章的注释续文**（本例 notes 文件开头是第十一章注 5/6/7）→ `initial_cur` 参数。
- **两册拼接**：上册末段无终止标点 → 与下册首段合并（`merge.py:join_volumes`，注意先按 `^\[\^id\]:` 切出脚注定义区，别把定义当正文）。下册缺「第二编」标题页 → 在 `## 第十章` 前补 `# 第二编 内战`。
- **OCR 整块丢失章节标题**：下册第十六章标题只留下副题行 `1861年—1862年`（layout page 135）→ 按上册目录补 `第十六章 蓄奴制与内战：北部的政策，1861年—1862年`（`extract_down.py:CH16_FIX`）。**不补则该章正文被算进上一章**，尾注链接会整章错位（ch15 链接数 25 > 附注 24、ch16 = 0 是典型症状）。
- **尾注链接方案**（正文→附注，非 pandoc 脚注）：正文 `<sup>K</sup>` → `<a id="enref-c{ch}-{K}" href="#en-c{ch}-{K}"><sup>K</sup></a>`；附注条目 `<a id="en-c{ch}-{K}"></a>{K}. 文本 <a href="#enref-...">↩</a>`，**只给正文确有标记的条目加 ↩**（否则产生 212 条死链）。重复标记（OCR 重复）只给第一个 `id`，后续只留 `href`，否则同文件重复 id。
- **必须跑 `fix_links.py`**：pandoc `--epub-chapter-level=2` 拆章后正文标记与附注不同文件 → 385 处 `href="#id"` 需改相对路径。校验看 `validate_epub.py` 的「内部链接 无效」必须为 0。
- **footnote id 跨册去重**：无页号的页用 pi 兜底会与另一册撞号 → `build.py` 加 `tag` 参数（下册用 `d`）。
- **`NOTE_MARK_OVERRIDE`/`FIXES` 按印刷页码匹配**，无页号的页会退化成 pi 造成跨册误命中 → 只在 `page['pageno']` 精确相等时应用。
- **诗行**：连续短块（≤34 字且含中文标点）跨页合并为一段，行间 `<br/>`（**必须自闭合**，pandoc 原样输出 `<br>` 会让 XHTML 校验报 mismatched tag）。小标题判定要排除以 `……`/`——` 结尾的行，但**不能**把 `—`/`·` 整体排除（会误杀 `“堪萨斯—内布拉斯加法案”`、`德雷德·斯科特案件的判决` 这类小标题）。
- **表格内脚注**：raw HTML 里 pandoc 不解析 markdown，星号注用 HTML 锚点 `tn{页}-{i}`；同一条注被两格引用时复用第一个锚点，避免重复输出注文。
- **形近字**：`淮州`→`准州`（34 处）；`“密苏里妥“协案”`→`“密苏里妥协案”`（跨页断行 + 多余引号）。
- **日期型假标记**：`[。！？”’）]\s*\d{1,3}(?=[\u4e00-\u9fff])` 命中大量「。5月11日」「。19世纪」→ **不能**当尾注标记，除非该数字正好是本章附注的下一个待补序号。

### 尾注标记恢复三步（按收益排序，均已脚本化）
1. `repair.py`（收益最大，本案例 127 处）：把 OCR 识别成普通数字的上标还原为锚点。**两个关键正则细节**：
   - 数字后**允许空格**——`(?=\s*[\u4e00-\u9fffA-Za-z“《（(])`。最初写成紧接中文，导致 126 处漏判（OCR 常在上标后留空格：`……趋势。”6␣␣南北战争前……`）。
   - 前置标点集合含 `。！？”’）]》`；数字后排除日期/量词（年 月 日 世纪 年代 时 人 名 个 次 多 余 万 亿 千 百 分之 等 以上 天 周 …）。
   - 三重校验才插入：章内序号单调且落在前后已知标记区间内、同一取值只取第一个、该章附注确实存在该编号。
2. 注释区粘连条目拆分（`extract_down.py` 定向后处理）：OCR 把 `18.` 读成 `18,`，使两条注释粘成一条（`…I, 406. 18, Takaki,…`）。规则：在上一条文本里搜 `\s{prev+1},\s+(?!Vol\.)(?=[A-Z][a-z]+[,.\s])` → 拆分。**不要用「逗号变体」做通用分条正则**（会把 `Ser. 1, Vol. 51` 误切成新条目，实测污染多章注释）。
3. `semauto.py`（专名定位，收益低但精度高）：用附注引证里的姓氏/报纸名（NameMap/PAPER_MAP 英文→中译）回到该缺号的前后已知标记区间内找「引号收尾」位置；仅当**唯一命中**时插入。本案例只成功 1 处（第8章 Yancey 演讲：附注即演讲原文出处，正文紧接该演讲引文）。其余多因中文译名与区间不唯一而跳过——**宁缺勿错**。

### 外部对照版（用户后来提供，2026-09-29）
用户先发了**第4版（2010，McPherson & Hogue）**扫描 PDF（3 分卷 817 页，有正常文本层，脚注为页底脚注、标记内联保留数字：`…agriculture.”2`），后补发**第1版（1982 Knopf，中译本所据版本）**扫描 PDF（3 分卷 764 页）。
- 两者的 marker 形式不同：**第4版保留数字**；**第1版 OCR 把上标统一变成 `^`（无数字）**，正文共约 367 个 `^`（含少量封面/地图噪声），而全书注释 352 条 → 标记基本齐全，位置可用。
- 但**版本编号不一致**：中译本第7章注10 = 第4版注13；第13章注3 = 第4版注14；第1章注4 = 第4版注5（第4版增添/合并了注释）。所以**不能按编号搬运**，也不能按引证字符串直接对号（第4版 144/352 条引证前缀变了）。
- 尝试过的自动定位（均不够可靠，未写入成书）：
  1. 用第4版带数字的句子做“句中年份/专名指纹”→中文缺号区间找唯一命中：84 条中 0 条可靠（第4版行文已改写）；
  2. 用第1版 `^` 句做指纹：仅 1 条可靠（候选因同年代数字（1844/1861）在英文里反复出现而并列，极难自动区分）；
  3. 用已链接的中文标记做锚点、按标记序列插值：只能生成 8 个单调锚点，不足以插值。
- 结论（重要教训）：**两个扫描件都缺页图像信息时，靠文本层做中英句级对齐不可靠**；可靠路径只有两条——(a) 直接拿中文扫描页图像读上标位置（47 页，确定性），(b) 人工逐条双语比对（可用第1版 `^` 句作为辅助，但需人判断）。**不要用“年代数字相同”自动插标记**。

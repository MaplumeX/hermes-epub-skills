# 案例：C.J.迪克《从失败到胜利》（两册相接 + 章末尾注 + 圈码误读）

台海出版社 2019，小小冰人译，军事史。两份 layout.json（A 200 页 / B 106 页）**按印刷页首尾相接**（A 到书 p183，B 从 p184 起），images.zip 30 张图全部命中。成品：一章一文件、126 条导航、316 KB 正文、epubcheck 0/0。

## 差异清单（换书时按这张表判，别复用阈值）

1. **两册页码偏移**：A 册 `pageno = pi − 16`（pi ≥ 15，前置页用罗马数字 I–XII），B 册 `pageno = pi + 184`；两册无重叠、无缺页，直接拼。
2. **两套注释**：章末数字尾注 223 条（序章 10、一 54、二 45、三 67、四 22、五 25，每章从 1 重编）+ 页脚圈码译者注 11 条。
3. **注区起点块类型不统一**：序章/一/二/三/四章是 `title` 块「注释：」，**第五章是 `text` 块**；第三章注区里还混着以 `19.` `21.` 开头的 `title` 块（其实是注文条目，不是小标题）——判注区一律按「从『注释：』到本章末」的页区间，不看块类型。
4. **注文条目分隔符三种**：`1.` `1、` `40。`（第 40 条用中文句号）。分条正则漏 `。` 会**整条静默丢失且 N 少 1**（本例第二章 N 从 45 掉到 44，后续所有号对齐全白做）。正则写 `^\d{1,3}\s*[.、．。]`。
5. **表格 19 张**（版权页 CIP 那张随版权页删，成品 18 张）：单元格里的上标有两种形态 `<eq>^{1}</eq>` 和 `<eq>1^{2}</eq>`（值 + 上标同一格），转换时保留前缀数字。表格直出原始 HTML（含 rowspan/colspan），不压 grid。
6. **表注与译者注同块类型**：`page_footnote` 里既有 `①译注：…`（→ 译者注），也有 `※资料来源：…` `1. 只统计82毫米…`（→ 该页表格的表注，输出到表后 `div.tf`）。判据只看开头：圈码 ≠ ※/数字。
7. **3 条「页脚块」其实是正文**（>200 字、含多个句号，讲兵力密度/突破速度/后续任务）——被 OCR 甩到页脚，直接当注文会毁掉正文结构；判据是长度+句读，接回该页正文末尾。
8. **8 幅地图的图题印在图内**，OCR 只给出图例（`图例：→ …`）和说明行。图题用 vision 逐张读图内印刷标题补（本例 地图1.1–2.4、3.1），图例单独输出 `div.legend` 小字，位置在「图 → 图题 → 图例」。
9. **正文用「地图X.Y」交叉引用**，可据此校验图 ↔ 图题 ↔ 页码对应（本例 8 处全部吻合）。
10. **章标题块缺前缀**：第一章、第三章的章名块只印「苏军1944年前的学说和实践」「1944年夏季，成熟的战役法」，没有「第一章」。章名以**书前目录**为准构造，块本身跳过（否则与 `#` 章标题重复）。

## 注释标记校准（本书最费工的一环）

- 源数据上标损坏率高：越界号（79/81/82/35/29）、同号重复、整处丢失并存；47 个标记要凑 54 条注。
- **并行 subagent 按章对齐可跑**（5 章派 5 个，1 个 600 s 超时；超时那章自己读，54 条注 + 47 个标记约 1 小时人工）；交付必须机械校验「序列 == 1..N」+ 我逐条复核 anchor 语义，**不能采信自述**。
- **序列校验通过不等于正确**：本书 3 处圈码（书 p70 ①、p143 ①、p209 ②）其实是注 53/45/56 被读成圈码。我把它们判成「缺注文」，在同章别处插了同号，六章序列全绿、epubcheck 0 error —— 错的。改判 + 删误插后仍绿，但落点才对。详见 M3 同名小节。
- **改动顺序**：`renumber（按索引）→ CIRC_AS_NOTE 改判 → drop → insert（按锚句）`。改判放到 renumber 之前会让索引整体错位一格（症状：总数 67、序列出现 `…57, 58, 38, 60, 63, 63, 44…`）。
- 第一章 2 处 OCR 重复标记（同段同号）按「一处落点」删除。

## 装配

`build.py → pandoc(epub3, --epub-chapter-level=1, --toc-depth=3, --css) → meta.py（封面/元数据）→ fix_epub_links.py → validate_epub.py → epubcheck`。

- 自写 HTML 段落（cap/tf/en/tn/legend/ref）一律用 **fenced div**，否则 `<p class="tf">1. …</p>` 会被解析成 `<ol>` 导致 `mismatched tag`（本书 3 个文件中招）。
- 封面取豆瓣 `subject_suggest`（`s29934948.jpg` → `/l/`），是**立体书影**，交付时说明。

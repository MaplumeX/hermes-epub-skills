# 案例：曼昆《宏观经济学》第十一版（中译本）layout.json → EPUB

源：三份 layout.json（A 200 页 / M 200 页 / B 159 页，539 有效页），`/root/mankiw_macro11/`。
与第十版案例的差异是**结构变了**（第8–10章扩成三章、共 20 章），不能复用旧脚本，须重新探索。

## 与第十版的关键差别
- 篇分隔页：只有 1–4 个块，页眉是 `第N篇`，正文块是竖排篇名（`导言`/`增长理论：超长期中的经济`）。篇名用固定表更稳：1 导言 / 2 古典理论 / 3 增长理论 / 4 经济周期理论 / 5 政策专题
- **章首页常常既无页眉也无页脚**（页脚章名缺失）：必须从页首 title 块判定章节。判定用 `第N章` 出现在文本任意位置且 len<60 —— OCR 会把章名拆成 `国民收入：源自何处？第3章 去向何方？`、`作为增长源泉之一的 第8章 资本积累`
- **个别章开篇页连 title 都没有**（B77 是第19章的题记页，整页只有 6 个正文块）→ 用 `OVERRIDE = {('B',77): 19}` 兜底
- 页脚章名会被 OCR 截成纯数字（`pn=10`、`pn=16`），`parse_pageno` 只取第一个数字，别拿它当章节依据

## 公式：用户要「可复制的 MathML」而非裁图
- `interline_equation` 同时有 `content`(LaTeX) 和 `image_path`(裁图)。第十版走裁图，**第十一版用户明确要 MathML** → `$$...$$` + `pandoc --mathml`
- 验证口径：解包后 `<math>` 数量 ≈ 行内公式数 + 独立公式数（本册 1959）；再剥掉 `<math>...</math>` 后搜 `\\[a-zA-Z]{2,}`，**必须是 0**（否则有公式退化成了 TeX 源码）。注意 `<annotation encoding="application/x-tex">` 里保留原始 TeX 是正常的，别误判为失败
- OCR 把数字拆开：`1 0 0`、`2 0 1 7`、`0 . 3`。`clean_tex` 里折叠 `(?<=\d)\s+(?=\d)`、`(?<=\d)\s*\.\s*(?=\d)`；行内公式也要过同一函数（`wrap_math` 对 `$...$` 段调用）
- `\begin{array}{r l}` 的列格式空格必须去掉，否则 pandoc 只给 WARNING 并把公式退化成源码

## 星号译注 vs 数学星号上标（本册最大坑）
- 页脚 `*` 译注（如 `帕里斯·希尔顿*出售`、`101^{*}`）与数学上的 `r^{*}`/`IS^{*}`/`k^{*}` 形态相同
- **apply_notes 必须先按 `$...$` 切段，只替换公式外的 `*`**；否则 `$r^{*}+\theta$` 里的星号被换成脚注引用，正文变成 `$r$[^p336-0]`
- 公式内部的标记也要先挪出来：`span_text` 里 `^(.*?)\^\{([①-⑳]+)\}$` → `$公式$标记`；**纯数字**后的 `^{*}` 才算译注（`^(\d[\d.,]*)\^\{(\*{1,3})\}$`），字母后的 `^{*}` 一律留在公式内

## 图表文字
- 图题在图块 `image_caption`、图释/说明/资料来源在 `image_footnote`；**很多图的题注直接烘焙在图里**，正文块里搜不到（图1-1/1-2 就是），所以「缺图题」先确认是不是本来就在图内
- `说明：`/`资料来源：` 开头的块必须独立成段（`block()`），否则页末 `…Foundation.` 会与下一页首段跨页合并
- 插图本体不在 layout.json 里（只有哈希文件名），须向用户索要；清单用 `figures.json` + 人读版 `缺图清单.txt`（页码+题注+文件名）

## 页边装饰条判定（本册踩过的两个错）
- 本书每页左右页边有章节色块（image 块，宽 40–55，x0≈0 或 x1≈504）。若不过滤，每页会多出一张竖条图
- **不能按 `x0<20 且 宽<220` 判装饰**：多图拼版的左半幅也会 x0 很小（图8-1 左图 x0=10、宽 106、右半幅才带题注），按旧规则会把半张图静默丢掉
- 正确规则：`kind=='image' and (x1-x0)<70 and (x0<=8 or x1>=496)`。`chart` 永远不判装饰
- 验证：过滤后再扫「窄于 70 但不在页边」的 image，应为 0；本书 404 个 image 引用 → 去掉 70 个页边条 = 243 张真图
- 图片包里还包含 370 张公式裁图（走 MathML 时用不上）与装饰条，所以 **压缩只压 book.md 实际引用的那批**

## 图片包（用户补发，2 卷）
- `images.z01`(5 MB) + `images.zip`(3.2 MB) → 保留原名同目录 `7z x -y -oout images.zip` → 817 文件，`Everything is Ok`
- 交叉核对：layout 全部 `image_path` 唯一值 817 = 解压 817，**missing 0 / unused 0**（这个双向核对必做）
- 体积：817 张共 11 MB；本书图本身很小（多数 <1000 px），`ffmpeg scale='min(900,iw)':-2 -q:v 6` 后 243 张 3.74 MB → EPUB 4.4 MB
- 抽查用 `vision_analyze` 直接看解出的图：确认「图1-1 人均实际GDP」「图14-2(a) LM曲线」内容与题注一致，比抽查 XML 更有意义

## 表格格式翻车（用户指着「1.3 里的关键概念」说格式有问题）
症状：成品里 `关键概念` 四列表变成 `<td>宏观经济学</td><td>| 实</td><td>际GDP | 模型</td><td><pre><code>   | 内生变量</code></pre></td>`。
根因是 **grid table 列宽用了 `len()`**（中文按 1 列算）→ 单元格溢出 → pandoc 把整行拆错。
修法见 SKILL.md「表格与双栏页」一节；本册具体踩到的四处：
1. `grid_to_md` 改显示宽度（`east_asian_width` W/F 计 2 列），修完 `关键概念` 四列干净对齐
2. **表6-1 的 `Y<C+I+G`**：裸 `<` 被 HTMLParser 当标签开头，整格变 `\( Y`；且源数据这格本身就被截断（`<td>\( Y</td>`），按同行另两列对称补全并写成 `$Y<C+I+G$`（`CELL_FIX` 表 + 白名单 `KNOWN_TAG` 转义）
3. **表2-1 跨页续表**：同页出现两张 grid table、表头重复。只删第二张表头两行 → 列宽不一致 → 非法 grid table。改成取两张 rows 合并后 `grid_to_md()` 重渲染
4. 表格校验脚本（本册新增）：解包后逐个 `<table>` 检查「去标签后是否还有 `|`」「是否出现 `<pre>/<code>`」「各行 `<td>` 数是否一致」——三者任一命中就是拆坏了；`validate_epub.py` 只数表格个数看不出来

## 双栏页排序（同一个「格式有问题」投诉的另一半）
- 症状：1.3 的「复习题 3」被排到「问题与应用」之后；`问题与应用 3` 被拆成「…价格的下」+「降会如何影响…」两段
- 纯列优先（左栏全部 → 右栏全部）会把右栏的复习题排到下一节标题之后。修法：**以本页 title 块的 y 为锚点先分小节，组内再按 左栏→右栏→跨栏 三档排**；跨栏块（`x0<230<x1`，如整幅表题）排该节最后
- 跨栏续文：左栏末块无终止标点 + 右栏首块不是新条目 → 直接拼接（`TERM` 正则 + `^\d+[.、]|^[A-D][.、]|^[a-d][.、]` 排除）
- **双栏 OCR 交错（信息已丢）**：A33（印刷页 14）的快速测验整块只有一个 span、line 无独立 bbox，左右栏按视觉行合并成 `A. 收入上升  B. 收入下降  B. 说明了外生变量如何影响内生变量`。栏位不可恢复，只能手写 `quizfix.py` 白名单（6 道题干齐全、选项按内容一一对应），build 里 `assert got == want`（原始片段集合 == 重构片段集合）守住；A167–169 的同类页题干跨页被截断，**保持原样不猜**
- 顺带：`快速测验` 条目要 `mergeable=False` 逐条成段，否则题干与选项被合并成一大段

## 表格：用户投诉「表格格式有问题」的完整根因清单（本节是重点）
1. **grid table 列宽必须按显示宽度算，不能按 `len()`**（根因，用户点名的 1.3「关键概念」就是它）：
   `len('通货膨胀与通货紧缩')==9`，但 CJK 占 18 列。按 len 算列宽 → 单元格溢出到相邻列 → pandoc 把整行拆错，
   XHTML 里出现 `<td>| 实</td><td>际GDP | 模型</td><td><pre><code>   | 内生变量</code></pre>`。
   正解：`unicodedata.east_asian_width(ch) in ('W','F')` 计 2，其余计 1；`w[i]=max(w[i], dw(c)+2)`，填充用 `' '*(w[i]-1-dw(c))`。
2. **单元格里的裸 `<` 会被 HTMLParser 当标签吃掉**：`<td>Y<C+I+G</td>` 只剩 `\( Y`。先 `re.sub(r'<(?!/?(?:table|tr|td|…)\b)', '&lt;', html)`。
3. **colspan 必须在同一行立即补空单元格**，不能塞进 `pending`（pending 只用于 rowspan 的后续行）：
   否则 `ci += colspan` 跳过 pending 键，后续列全部错位（表14-1 的「固定汇率」跑到第3列）。
4. **展开出来的重复值只保留第一格，其余留空**：grid table 不支持合并，否则表头变成「政策 政策 政策 汇率制度 汇率制度…」。
   实现：expansion 时给每个单元格带 `span` 标志（同结构二维数组），caption 列删除之后再统一置空。
5. **跨页续表合并**：两表之间只有空行且表头（去空格）相同时合并；**必须用统一列宽重新 `grid_to_md`**，
   直接删掉第二个表头会留下不同 padding 宽度 → 非法 grid table。
6. **源数据单元格截断**用 `CELL_FIX` 定点补（表6-1 第4行第3列是 `\( Y`，按同行另两列对称补成 `$Y<C+I+G$`）。
7. 术语表/关键概念里 `[参看…]` 交叉引用不能被当成新词条切开：`re.split(r'(?<=[。\]])\s*(?![\[参])(?=[^（）]{1,40}（[A-Za-z])', t)`。

## 关键概念列表：`in_keyconcept` 状态必须跨页持久
原实现每页开头 `in_keyconcept=False`，而「关键概念」标题与词条常在**不同页** → 有的章渲染成项目符号、有的章变成普通段落。
改为在 `main()` 作用域初始化一次，只在切换章节/出现其它标题时重置；词条按 `\n` 与 2+ 空格双分隔切（`'贸易平衡 小型开放经济世界利率'` 这种粘连是右栏词条粘上来的，无分隔符时不要硬切）。

## 标题判定：以问号结尾的标题会被判成正文
`classify_title` 的排除集 `[。；！？]` 把「参考资料 信用卡和借记卡是如何适应货币系统的？」判成 text → 标题变段落且空格被折叠。
改为 `s.rstrip('？?')` 后再判；修完 h4 从 495 增到 522，需抽查确认没有把正文句子升成标题（本册无）。

## 双栏快速测验的 OCR 串行（第1章 p14、第6章 p148-149）
双栏页里同一 text 块只有一个 span、line 无独立 bbox → 栏位信息彻底丢失，原文变成
`A. 盈余，升值    B. 盈余，贬值    A. 减税    B. 投资增加` 这种左右栏交错。
做法：写 `quizfix.py` 表（按 `(file,pi)` 键），**只重排、不增删**——build 时用「非空白字符多重集相等」断言把关；
跨页题（第6章第2/3题题干被页边界截断）按「左栏读完再读右栏」的顺序拼接；
确实整处缺失的题干（第6章第5题）写 `5. 〔题干在版面数据中整处缺失，仅存选项〕`，**不猜**。
渲染：题干预选项之间用 `|` 分隔，build 时换成 `<br/>`，避免 pandoc 把 A./B./C./D. 识别成有序列表。

## 章末双栏（快速测验 / 问题与应用 / 复习题 / 关键概念 / 内容提要）

### 最大陷阱：页底正文被 OCR 判成 footer，整段丢失（不是排版问题，是内容没了）
版面数据把每页底部块放进 `discarded_blocks`，类型常是 `footer`。旧规则只捞「带句末标点且 >40 字」的，于是：
- 第18章内容提要第4条整条消失；第19章内容提要第4条只剩半句；
- 第19章问题与应用 a/b 小题、第20章多条提要、图20-6 图题与图注全部丢失；
- 页脚里跨栏被切开的句子也丢。
修正：`header/footer` 只排除**真正的版式行**（书名、章名、篇名、页码、`续表`、`Preface`、网址、以及源 PDF 混入的无关公告），
其余一律当正文收。实测收回 42 个块、约 1750 字。
**自检脚本**：把每个 `header/footer` 块的非空白字符与 book.md 做包含比对，报告「找不到的块」，人工看一遍——
这一步能直接发现内容丢失，比字符数比率靠谱。

### 关键概念：重复/残缺词条（用户第三轮投诉）
原书「关键概念」是多栏列表，OCR 把多栏读成一段文字，产生三类错误，**不要用纯启发式拆词**：
- A) 词条被换行切断：`实际 / 工资`、`基础 / 货币`、`百分之百 / 准备金 / 银行制度`、`事前 / 实际利率 / 和事后 / 实际利率`
- B) 相邻词条粘连：`柯布-道格拉斯生产函数可支配收入`、`古典二分法货币中性`、`微观审慎监管金融危机`
- C) A+B 叠加 → 同一概念在列表里出现 2–4 次（`货币`x4、`准备金`x3）

解法（`kcfix.py`）：以「正文 `中文（English）` 术语」+「术语表加粗词条」+「各列表原有词条」建词典，然后
1. 先去句首连词（`和事后` → `事后`），再按 ` vs. ` 拆分/拼接（`局内人`+`vs. 局外人`）；
2. 合并残缺相邻项：`a+b` 或 `a+b+c` 在词典里，且其中至少一项不是独立词条（或本列表存在重复）；三连要**先试**，
   否则 `百分之百 / 准备金 / 银行制度` 会先错并成 `准备金银行制度`；
3. 拆分粘连项：整段能切成 ≥2 个词典词条才拆，否则原样保留；
4. 去重（保留首次出现）。

**必须避开的坑**：
- 词典从「英文括注前的汉字串」取后缀时，正则要允许英文以**数字**开头（`（100-percent-reserve banking）`），
  且字符类要包含 `-—·` 和空格，否则 `百分之百准备金银行制度`、`LM 曲线`、`IS—LM 模型` 都进不了词典。
- 后缀最短长度设 4：短于 4 的碎片（`主义者`、`实际`）不能进词典，否则它们会被当成独立词条，粘连项永远并不上。
- 把「列表原有词条」补进词典时要跳过**能被切开**的长项，否则粘连项自我合法化，永远拆不开。
- 个别「拼起来也像术语」的独立词条要显式排除：`KEEP_SEPARATE = {('货币','铸造税')}`。
- **同一「关键概念」小节常被页/栏切成多个 `- ` 块**（中间夹空行），必须按小节而不是按块处理，
  否则去重/合并只在半截列表内生效。
- `kcfix` 重写小节时，非列表块（如 1.3 的表格）必须**整块原样输出**，逐行拆开会把 grid table 拆碎。
- 关键概念里被 OCR 标成 `title` 的词条（`资本的黄金律水平`、`冲击`、`稳定化政策`）也要当列表项；
  但 `text.strip() not in SEC_TITLES` 必须先判，否则「复习题/内容提要」会被吞进列表且 `in_keyconcept` 不复位，
  后续整章结构（h2/h3/h4 数量）会崩。

### 插图位置：不能把段落/引导句切开（用户第九轮：图片要放在文本中的合适位置）

三类错位，先建探测器再修：

**A. 图插在段落中间**（前段结尾无句末标点、后段接着把这句话写完）
探测器：对每个图组 [a,b)，`blocks[a-1]` 不以 `[。！？…”』」）】：；]` 结尾，且 `blocks[b]` 不是标题/列表/公式。
修法：`merged = prev + next`，图组整体移到 merged 之后。
陷阱：OCR 页底会把图的脚注单独输出成一段，夹在图组和续段之间。先判断「候选块是完整单句（一个 `。`、≤140 字）+ 它的下一块才是续段（以 1–4 字短片段开头，如 `数。正如…`）」→ 候选是游离图注，要并进引用块而不是拼进段落。

**B. 图插在「引导句 → 公式」之间**（如「柯布-道格拉斯生产函数是」+ 图 + `$$Y=AK^αL^{1-α}$$`）
修法：图组移到引导句之前。注意**要跑两遍**：第一遍把段落拼完整后，图才会露出「后面跟 `$$`」的形态；只跑一遍无效。

**C. 图插在「引导句 → 项目列表」之间**（「下面是一些例子：」+ 图 + 例子列表）
修法：图往前移到最近的小标题之前，落到上一节末尾。本例图11-13 属于「对总需求的冲击」节，OCR 把它放在下一页页首，拼段后就漂到了下一节中间。

验收：`把段落切断的图组 0`、`夹在引导句与公式之间 0`、`插在引导句与列表之间 0`、
`图组位于章末双栏小节内 0`、`图组紧贴标题 1`（附录八图，正常）。
另外用「源文本块探针」校验合并没有吞字：每块取中间 40 个汉字查是否出现在 md 里，缺失应仅剩双栏 quiz 重排的 4 块。

### 图片附属文字用 blockquote（用户第八轮：图片的脚注、文本用 md 引用格式）
目标形态：图 → `> **图X-Y 标题**` → `>` → `> 图注` → `>` → `> 资料来源：…`，在阅读器里显示为一个缩进引用框。

实现要点：
1. 图片分支输出时，图题/面板标签/图注/资料来源都加 `QB = '> '` 前缀。
2. **所有后续 md 后处理必须能处理带 `> ` 前缀的块**：加 `_unq(t)` 剥前缀，`_fig_cls`、`CAP_B.match`、
   `move_caption_after_image`、`apply_fig_group_fix`、`fix_fig616`、`fix_split_figure_text` 全部改用 `_unq(...)`。
   漏一处就会静默失效（图12-7 的 (a) 图就因此又跑回正文后面）。
3. 重写图题/标签时要把 `> ` 加回去（`'%s**%s**' % (QB, ...)`），否则引用格式被抹掉。
4. `merge_quote_blocks`：相邻引用块用 `\n>\n` 合并成一个（图题+图注+资料来源同一框）。
5. **独立图注段落也要吸收**：图注常被 OCR 切成独立 text 块（不在 figure 的 footnote 里）。
   判据：紧跟图题引用块、且（含「说明：/资料来源：」或 以「图（a）/本图」开头）。
   **不能用「该图」「图中」开头做判据**——那是正文（如「该图所显示的正相关性是一个重要事实…」）。

验收：`图片 224，其后紧跟引用块 205`（差 19 = 多面板图中间的面板图，后面跟下一张图，正常）；
`超长引用块 0`；`引用块内出现「图X-Y 显示了…」正文引导语 0`；EPUB 里 `<blockquote>` 数 == 引用块数。

### 图题与图片「一一对应」的校对方法（用户第七轮：校对让图片和图题对应）

**先建立可验证的不变量，再逐项修**：
1. 图题按出现顺序，图号必须**单调递增**（图1-1 → 图1-2 → … → 图20-8）。顺序异常 = 图题错配。
2. 每章图号必须**连续无缺**（缺 图6-11 说明那张图的图题丢了）。
3. EPUB 里每张 `<img>` 之后**必须**紧跟：图题 / 面板标签 / 下一张面板图。这条能拓到 0。
4. 抽样送视觉模型：读图里的坐标轴与曲线，与图题文字对得上。

**踩过的坑（都是真错，不是误报）**：
- **图题排到了别的图前面**：OCR 把图题挂在空白误识块上，删空白图后图题就落到相邻图的图注前面，看起来像「图1-1 的图题配了 图1-2 的图」。
  修法：空白块的图题**挂起**（`pending_fig`），贴到下一张真图后面。输出顺序固定为：图 → 面板标签 → 图题 → 图注。
- **面板标签张冕李戴**：OCR 把右栏 `(b)` 读在左栏 `(a)` 前面，且标签有时挂在错的面板上。
  修法：**页级分配**——先看每图自带几个标签；若标签总数 == 图数但分配可疑，就按字母序配 (y,x) 序；
  否则按 y 距离就近配。**不要在 md 层按字母重排后重新配对**，那样会把已配对的弄乱。
- **多面板图被拆到两栅、顺序完全错乱**（图12-7：`[b+c 图][图题][图注][a 图]`；
  图14-1：`[b图][c图][c标签][图题][图注][a图][a标签]`）：通用规则救不了，用显式表 `FIG_GROUP_FIX`
  列出「图题键 → [(哈希, 标签或 None), …]」，把图与标签整体搬到图题之前。
- **附录八图的图题烘在图内**，OCR 只读到「资料来源」。逐张读图把图内标题原文记到 `FIG_TITLE_FIX`
  （这不是补写，是读图）。注意无编号图题（如「失业率」）会让「图题是否加粗」的判据失效——
  要额外允许「无编号短标题」也加粗，并排除以数字/括号开头、含「……」的图内注释。
- 图题可能重复出现一次在 caption、一次在 footnote，要按去空白后的字串去重。

**检查脚本的局限**：判「图后是不是图题」时，必须把「下一块是另一张面板图」也算合格，
否则多面板图会大量假阳性（我从 19 个假阳性降到 0 才发现这一点）。

### 图题排版统一（用户第六轮：为什么有的在前有的在后有的没格式）
先查**根因**再动手，这里有四个独立成因：
1. **图题字段根本没读到**：`chart` 块的子块类型是 `chart_caption`/`chart_footnote`，`image` 块是 `image_*`。
   只写 `subblocks(b,'image_caption')` 会丢掉全部 132 条 `chart_caption`——症状就是「有些图没标题」。
   实测子块分布：`image_body 292 / chart_caption 132 / image_caption 122 / chart_body 116 / chart_footnote 45 / image_footnote 42`。
2. **图题位置**：默认「图题在图后」；OCR 把图题读在图前（典型是空白块在图左、真插图在图右，图题挂在空白块上），
   需要 `move_caption_after_image()` 把「图题 + 中间夹的图注」整体搬到图后。
3. **格式三种混用**：`**bold**` / `*italic*` / 纯文本。统一为加粗。面板标签（a）/（b）同样处理，
   注意全角 `（a）` 必须一起认，否则漏。
4. **面板标签顺序乱**：OCR 常把右栏（b）读到左栏（a）前面。修法：把一组图的面板标签**按字母排序**后与图按顺序配对，
   输出「图(a)、标签(a)、图(b)、标签(b)…图题」。

**踩过的坑**：
- `panels.sort(key=lambda t: t[2].lower())` —— 加粗后 t = `**(a) …`，`t[2]` 永远是 `(`，排序静默失效。
  要 `re.search(r'[（(]\s*([a-fA-F])', t).group(1)` 取字母。
- 图题字段里可能混进**正文段落**（`图1-3显示了美国的失业率。…`）或**图内编号注释**（`3. ……导致了一场衰退`）。
  不加判据直接 `**%s**` 会把整段正文加粗。判据：`^图\d+-\d+\s` + 无句号 + 长度≤50 才算图题。
- 同一图块里 caption 可能有多段（真图题 + 图注）：抽取时把「图X-Y …」排到最前，其余按序跟在后面。
- 图内**坐标轴标签**会被读成独立段落（`实际利率，`、`投资，储蓄， I， S`）。
  只能删「以逗号结尾且紧跟图题」的短块——`式中，`、`或者等价地，` 也是这种形式，删了就丢正文。
- 极少数图被拆到两栏且顺序完全错乱（图6-16：`[b图][图题][b标签][a图][a标签]`），
  通用规则救不了，用一张显式哈希表 `FIG_ORDER_FIX` 重排，并在注释里写清原顺序。

验收（都在 EPUB 里查，不只看 md）：`图 %d；其后既非图题也非面板标签的 N 个` 应为 0
（附录「八个重要变量」的图标题烘在图片里、只剩「资料来源」，属正常）。
**但这个按图片数的指标会误报多面板图组**（图后紧跟另一张图是正常的），真正可靠的判据是
「按图组统计 + 逐章图号 1..N 无缺口 + 抽样看图核对图题内容」，见案例文件同名小节。

### 空白误识图（用户第五轮：指定 fileN 要删）
OCR 把页面空白/页边残条也当成了插图。它们和真插图**紧挨着**（同一页、同一 y 区间、x 相接），
所以用户看到的症状是「图还在，但旁边多一张空白」。

定位方法（关键：**别用 book.md 的图片序号去猜 fileN**）：pandoc 从 `file0.jpg` 开始顺序编号，
但和 book.md 图片序号差 1 且分栏/跨页会错位。可靠做法是**字节比对**：
`md5(EPUB/media/fileN.jpg) == md5(images/<hash>.jpg)`，源图在本地就是同一份压缩产物，243/243 全匹配。
拿到 hash 后写进 `build.py` 的 `BLANK_FIGS` 黑名单，保证可重建（不要手工改 EPUB）。

两个坑：
1. **黑名单哈希要和 `.jpg` 后缀解耦**：`it['figs']` 里带 `.jpg`，黑名单里存的是裸哈希，
   必须先 `os.path.splitext(f)[0]`，否则 `is_blank_fig` 永远返回 False（静默失效，`fig` 数不变）。
2. **空白块的 caption 可能是正牌图题**：如 A76 的空白块 cap=`图3-6 消费函数`，真插图在它右边且 cap 为空。
   直接 `continue` 会丢图题。正确做法：`src = None` 但**继续走 caption/footnote 分支**，并且不能输出
   `*〔图〕*` 占位、不能计入 `fig_missing`（单独计数 `fig_blank`）。

验证：删后 `fig 243 → 224`、`fig_blank 19`；EPUB media 224 张，19 个哈希 0 残留。
**批量判定空白**：`ffmpeg -vf scale=64:64,format=gray -f rawvideo` 后算灰度标准差——
这 19 张 std 4.7–8.5、均值 207–230；剩下 224 张里最淡的 std 9.67，分界干净。
注意不能用「墨点比例」判：书中大量白底折线图 ink 也只有 0.01。

### 章末栏目「多题排在一行」的四类根因（用户第四轮投诉）
用户原话：「有些复习题的排版还是没整理好，出现了多题排在一行」。别只看段落文本，**先查 markdown 的换行**：
markdown 里单个 `\n` = 空格，所以「两行相邻但中间没空行」的独立条目会被 pandoc 并成一段。自检：
找出「前一行和本行都以题号/选项/小问标记开头、中间无空行」的相邻对——这比看渲染结果快得多。

四类根因与修法：
1. **相邻行无空行**（快速测验答案 `1\. A / 2\. D / …`、第4章复习题、第5章内容提要）
   → `split_adjacent_numbered()`：两行都以 `\d{1,2}[.、]`（或 `[a-hA-D][.、]`）开头就插一个空行。
2. **多题并进同一段**（`…需要什么数据？3.政策制定者…`）
   → `split_embedded_numbered()`：只在章末栏目内，按「句末标点 + 题号」切开。
   坑：用前瞻匹配 `(?=(\d)[.、])` 时**前瞻不消耗字符**，切出来的片段仍以题号开头，必须再剥一次，
   否则得到 `3\. 3.政策制定者…` 双重题号。
3. **答案成串**（`1.B 2.D 3.C …` 一行）
   → `split_answer_run()`：仅限「快速测验答案」小节。注意首项可能已被 `fix_text` 转义成 `1\.`，
   正则要写 `^\d{1,2}\\?\s*[.、]`，否则整行被跳过（这个坑踩过一次）。
4. **小问 a./b./c. 粘连**（`…的影响： a. …。 b. …。`）
   → `split_embedded_subq()`，仅限「问题与应用」。注意：拆开后 pandoc 会把 `a.` 开头的行自动变成
   `<ol type="a">`，这是好事（阅读器按 a/b/c 自动编号），不算丢字。

### 关键概念与上一栏目错序（同一批反馈里发现）
双栏页里侧栏的「关键概念」块常被 OCR 排在主栏续文**之前**，导致「内容提要 5、6、7 条」跑到关键概念列表后面。
→ `fix_endmatter_order()`：关键概念之后若还有以「大于上一栏目最大题号」开头的段落（或无题号的续文），
搬回上一栏目末尾；搬完**必须再跑一次 `merge_section_continuation`**，否则孤立的续文（`名义利率与实际利率又取决于…`）
会自己占一段。
**kcfix 也要配合**：重写关键概念小节时，`other`（非列表行）如果一次性 `out.extend(other)` 就会再次粘成一行——
表格行（`|`/`+`）整块输出，其余行逐段输出并补空行。

### 选项排版（用户投诉「左右栏内容混在一起 / 没换行」）
根因不在双栏排序，而在**只有标为 quiz 的块走了选项格式化**，双栏页里的 `问题与应用`、`复习题` 走普通段落分支，
`A. … B. … C. … D. …` 全糊成一行。修复要点：
1. 任何含 ≥2 个选项标记（`(?<![A-Za-z])[A-D]\s*[.、]`）的块都走选项格式化，而不是只认 quiz。
2. 切分要过三道：题干与选项粘连（`…是多少？A.0.02`）、选项之间只有空格（`A. …    B. …`）、
   下一题号粘在上一行末尾（`…受多大影响<br/>6. 美国和西欧…`）。
3. **必须先 fmt_quiz 再 fix_text**：`fix_text` 会把 `1.` 转义成 `1\.`，题号正则就认不出了。
4. 选项字母乱序（第20章出现 `A/D/C/D`）：一组正好 4 个选项时按位置纠正为 A/B/C/D。
5. 选项被拆成两个相邻段落（A/B 一段、C/D 一段）→ 合并；题干被栏/页切成两段（短的那段是长的那段前缀）→ 去重。
6. 题干被切断、续文单独成段（`上方倾斜。`）→ 小节内「不以题号开头的段落」拼回上一段；
   **但 关键概念 是项目符号列表，绝不能参与这个合并**（否则两个词条会被粘成一条）。
7. 验收：`全书的 <br /> 总数` 应达到数百；「同一行里挤了 ≥2 个选项的段落」应为 0（英文文献里的 `A.` 作者缩写是误报）。

### 关键概念词条粘连
OCR 会把相邻几个词条读成一行（`国民收入核算恒等式消费 投资`、`逆向选择道德风险`）。
用书末术语表的词条集合做贪心最长匹配，整行能完整切成 ≥2 个术语时才拆，否则原样保留。
**踩过的坑**：给「2–4 字短词」开后门时必须排除以 `与和的之及或` 结尾的片段，否则 `存量与流量` 会被切成 `存量与`+`流量`。
含 ASCII 字母的行（`经济利润 vs. 会计利润`）一律不动。

## 公式排版（用户第二轮投诉「公式排版不好」）
用户会拿具体段落对：「3.4 里『下列方程总结了…』下面的几个公式排在一行了」。逐条根因：
1. **多条独立公式被粘成一行**：OCR 把 5 个公式放进一个 `code`/`text` 块，每行一个 inline_equation，但
   `alltext` 用 `\n` 连接、markdown 里单个换行 = 空格 → 渲染成一行 `$Y=C+I+G$$C=C(Y-T)$…`。
   检测：块内容整体匹配 `^(\$[^$]+\$\s*)+$` 且公式数≥2 → 逐条输出 `$$...$$`。
   变体：块首还有一句导语（「模拟采用的参数值如下：」）→ 只把那一行纯公式串拆开，导语单独成段。
2. **`\tag{X}` 被 texmath 静默丢弃**（不报错！）：IS/LM/DAS/DAD 这些标注会凭空消失。
   转成 `\qquad \text{(IS)}`，实测 pandoc 能正常转成 `<mtext>`。
3. **多行等式不对齐**：`\begin{array}{l}` 里每行都是完整等式（方程组）时没有 `&`，单列左对齐，`=` 对不齐。
   转成两列：每行在最外层第一个 `=` 前插入 `&`，spec 改 `{rl}`（要先去行首尾的 `{...}` 分组括号）。
   注意 `=` 要排除 `==`、`<=`、`>=`，且要跳过 `\text{}` 内部。
4. **「等式+右侧标注」两列（`{l l}`）**：第一列再按 `=` 拆开 → 三列 `{rll}`。
5. **OCR 把 IS*/LM* 标注单独识别成公式块**（M155）：方程组后面跟着 1–2 个极短 interline_equation（无 `=`、≤14 字），
   把它们作为第三列贴回方程组。**只有真的贴上才吞掉那些块**（attach 返回原值就别 skip，否则标注静默丢失）。
6. **MathML 层面补保险**：部分阅读器忽略 `<mtd columnalign>`，默认按居中 → 多行等式仍会错位。
   EPUB 打包前遍历 xhtml，给每个 `<mtable>` 按首行 mtd 补 `columnalign="right left"`（脚本在 add_metadata.py 里，实测 12 个文件命中）。
7. 编号方程清单（「综合模型有7个方程」）每行 `$公式$  说明` → 拆成独立显示公式 + `\qquad\text{(说明)}`；
   导语被 OCR 重复读一遍时（前一块末尾 + 本块首行）要去重。

## 内容真丢失：页底正文被 OCR 判成 `footer`（第三轮投诉的隐藏根因）
用户说「章末双栏部分排版有问题」，查下去发现**不只是排版乱，是整段没了**：
`extract.py` 从 `discarded_blocks` 里捞正文时用了「`len>40` 且含 `。！？`」的启发式，于是章末双栏区一批段落被静默丢弃：
- 第18章「内容提要」第4条（李嘉图等价整段）
- 第19章「内容提要」第4条只剩半句（「源泉，因此，一个运行良好的金融系统…」）
- 第19章「问题与应用」a/b 小题、第20章多条提要、图20-6 的图题与图注
- 跨栏被切开的句子（`融资的减税____。`）

**正确策略：黑名单，不是白名单**。页眉/页脚里只排除**确实是版式**的行，其余一律当正文收回：
```python
NOISE_HEADFOOT = [书名, r'\d{1,3}[.\s]*书名', r'\d{1,3}[.、]?$', '续表', 'Preface/Contents',
                  r'第\s*\d{1,2}\s*章\s*.{0,30}', r'第\s*[一二三四五六]\s*篇\s*.{0,30}',
                  r'结束语\s*我们知道什么.{0,20}', r'\d{1,3}\s+第\s*\d{1,2}\s*章']
JUNK = ['上海浦东发展银行', '募集资金进行现金管理']   # 源 PDF 混进来的别本书内容
# 另加：含 macmillanlearning 的网址行
```
`header` 里的短行（≤30 字、无句读）判 `title`（如「问题与应用」「经济学家和公众对通货膨胀的看法」），其余判 `text`；
`footer` 里 `^图\s*\d+-\d+` 判 `title`（图题被 OCR 塞进页脚）。实测回收 42 块 / 1750 字。

**验收脚本（必做）**：逐页取 `discarded_blocks` 的 header/footer，去空白后若**不在 book.md 里**且不是版式噪声 → 报丢失。
初版扫出 306 块，扣掉书名/页码噪声后剩 42 块真正文。

## 双栏「选项全挤成一行」的完整修法（用户第三轮投诉）
章末 `问题与应用`/`复习题` 走的是普通段落分支（只有 `快速测验` 被标成 quiz），所以 `A. … B. … C. … D. …` 全糊成一行。
按顺序加这五道处理（`build.py`）：
1. **判定**：块内 `(?<![A-Za-z])[A-D]\s*[.、]` 出现 ≥2 次 → 当选项块，走 `fmt_quiz()`
2. **切分**（`fmt_quiz` 内，按序）：
   - 题号粘在上一行末尾：`(?<=[\u4e00-\u9fff）)。])\s*(?=\d{1,2}\s*\\?\s*[.、](?!\d))` → `\n`
   - 题干与选项粘连（`…是多少？A.0.02 B.0.04C.0.05`）：`(?<=[^\sA-Za-z])\s*(?=[A-D]\s*[.、])` → `\n`
   - 选项间只隔空格（原书一栏放两个）：`[ \t]{2,}(?=[A-D]\s*[.、])` → `\n`
   - 兜底 `OPT_SPLIT = (?<=[汉字）)。，、；：$%\]】」』”0-9])[ \t]*(?=[A-D][.、])`
3. **选项字母乱序**（第20章出现 `A. / D. / C. / D.`，第二个选项被 OCR 读成 D）：一组正好 4 个选项时按位置重写为 A/B/C/D
4. **相邻两个纯选项块合并**（A/B 一段、C/D 一段）：`merge_option_blocks(md)`，上一段最后一行以 `[A-D][.、]` 开头即合并
5. **题干跨栏被切成两段、短的是长的前缀**（`6. 美国和西欧的工作小时数差别的解释之一` + 完整句）：`dedupe_prefix_blocks(md)`，只在两段同题号且一段是另一段前缀时丢短的

### 致命顺序陷阱：`fix_text` 先把题号转义了
`fix_text` 有 `re.sub(r'^(\d{1,3})\.\s', r'\1\\. ')`（防 pandoc 把 `1. ` 当有序列表）。**若先 fix_text 再 fmt_quiz，`1\.` 就匹配不上题号正则，整题拆不开**。
正确顺序：`for _g in fmt_quiz(text): block(apply_notes(fix_text(_g, collapse=False), pg))` —— 先按原始文本分组，再逐块转义。

### 验收
`chk_secs2.py` 模式：按 `#### 快速测验` 等小节切块，逐行归类 `N`(题号)/`O`(选项)/`X`(其它)，输出序列串 + 异常（题号不是 1..6、A 或 D 计数≠6、游离文本）。
修完 19 个快速测验节全部规整，只剩 7 处单条游离（跨栏一句话被切开、无法自动判定归属，留人工）。

## 图题（用户第六轮：位置/格式不统一、部分图没有标题）

五个独立根因，逐个查：

1. **`chart` 块的图题子块类型是 `chart_caption`/`chart_footnote`，不是 `image_*`**。
   只收 `image_caption`/`image_footnote` → 本书 **132 条 chart_caption 全丢**，症状正是用户说的「有些没有相应的格式／没有标题」。
   实测子块类型分布：`image_body 292 / chart_caption 132 / image_caption 122 / chart_body 116 / chart_footnote 45 / image_footnote 42`。
   修：两类都收；同一图块若含多段 caption，把真正的 `图X-Y …` 排最前
   （`caps.sort(key=lambda t: 0 if FIGNO_RE.match(t) else 1)`），图注/说明按原顺序跟后。
2. **三种格式并存**：`**bold**` 70 处、`*italic*` 8 处、纯文本无格式 10 处（图6-19、图6-22、图11-6、图13-4、图13-7、图14-6、图14-7、图14-16、图20-7 等）。
3. **图题排在图前**（5 个主图题 + 2 个面板标签）：根因是这些页「空白误识图在图左、真插图在图右」，图题字段挂在左边空白块上；
   删掉空白图后图题就落到真插图**前面**了（空白图修复的连带副作用，删空白图时必须同时检查图题落点）。
4. **caption 字段里混进正文段落**：`图1-3显示了美国的失业率。注意…` 被整段加粗成图题。
   判定真图题：`^图\s*\d+[-–—]\d+\s` **且无 `。` 且 len≤50**；否则按正文 `block(fix_text(...))` 输出。
5. **图内坐标轴标签被读成正文**：`投资，储蓄， $I$ ， $S$`、`净出口， $NX$`、`收入，产出， $Y$`、`失业率， $u$`
   ——这些字图里本来就有，白名单删掉。**别用「短+含逗号」这种启发式**，会误删真图题。

另有一类「半句进了上一张图的 caption」：`图1-3显示了…尽管不同年份`（无句末标点）被页边界切断，后半截 `的失业率差别很大…` 留在图后。
`fix_split_figure_text()`：找 `^图X-Y` 无句末标点的块 → 定位该图图题块 → 取图题之后第一段以 `的/了/是/和/与/而/但/并` 开头的续文 → 拼接后放到图题后面。

归一化函数 `normalize_figures(md)`：把连续的 `img/cap/panel` 块当一组（`md.split('\n\n')` 后按块分类），
组内 **图在前 → 面板标签紧随 → 主图题收尾**：单图 = `img + panels + caps`；多图且面板数 == 图数 → 图-标签交替；
否则图全部在前、标签随后、图题最后。**面板标签正则要覆盖 a–f**（原 `[a-c]` 漏掉 `(d)(e)`，5 图/4 图面板图被误判「无图题」）。

管线顺序：`drop_axis_noise → fix_split_figure_text → normalize_figures`，都在 `merge_split_tables` 之后、脚注定义之前。

### 图题↔图片配对：三条会把图题搬到**别的图**上的错误规则（用户第七轮：「校对让图片和图题对应」）
上一轮只做到「位置/格式统一」，配对本身是错的。三个坑，症状都是「图题看着有，但配的是隔壁的图」：

1. **「往前找 3 块内的图」会把图题搬过界**。`move_caption_after_image` 若允许跳过中间段落去找图，
   图1-1 的图题会越过图1-2 的图落到图1-2 后面（图1-1 与图1-2 紧挨着，中间只隔一段图注）。
   正确规则：**只有「图题紧跟着就是图」才搬**（`i+1` 是 img）；再放宽一点也只能夹**自己的**图注，
   判据是中间段落里出现的图号必须等于图题自己的图号（`re.findall(r'图\s*(\d+-\d+)')` 逐个比对），
   提到别的图号 → 这段属于那张图，停。
2. **空白误识图的图题要「挂起」，不能就地输出**。删掉空白图后若仍把它的 caption 就地 `block()`，
   图题会落在真插图**前面**。改为两个待处理队列 `pending_fig = [[图题], [图注]]`，
   遇到空白图只入队，遇到真图再吐出，顺序固定为
   **图 → 面板标签 → 本图图题 → 挂起图题 → 本图图注 → 挂起图注**（图题必须紧跟图，图注在图题之后）。
3. **面板标签不能「收集全页标签再按字母排」**。标签归属由坐标决定，不是由字母决定：
   - 优先用**各图自带**的标签（`chart_caption` 里常是 `图6-19 …\n(b) 资本净流出`，标签就嵌在 caption 里，
     必须先拎出来，否则它会被当成图注印在图题下面）；
   - 若「全页标签数 == 图数」但有的图没标签，则**整体按字母序配 `(y, x0)` 序的图**（先上后下、先左后右）；
   - 只有配对确定之后，才允许按字母排**显示顺序**。
   排序 key 用 `re.search(r'[（(]\s*([a-fA-F])', t).group(1)`，不要用字符串下标（加粗后 `t[2]` 恒为 `(`，
   排序静默失效——这个坑踩过一次）。

**验收指标换成「按图组 + 按章连续」，不要数「图后紧跟不是图题」的图片个数**：
多面板图组本来就是「图后面紧跟另一张图」，按图片数会得出 28 个假异常。正确做法：
- 把连续 `img/panel` 块算作**一个图组**，取组后第一个 `**图X-Y …**` 作为该组图题；
- 逐章检查图号 `1..N` **无缺口且单调递增**（本册 171 组 / 162 个图题 / 20 章，缺口 0、顺序异常 0）；
- 抽样 **看图**核对：把关键图 hash 复制出来交 `vision_analyze` 读「纵轴/横轴/曲线是什么」，
  与图题逐字比对（本册验过 图1-1 人均实际GDP、图1-2 通胀率、图1-6 (a)需求/(b)供给、
  图6-16 (a)垂直CF/(b)水平CF、图15-4 菲利普斯曲线、图20-6 资本租赁市场——全部对上）。
  这一步能抓出「面板标签张冠李戴」，光查文本查不出来。

验收脚本（都要跑到 0）：
- `chk_cappos3.py`：真正在图前的图题 / 面板标签数
- `chk_capfmt2.py`：未加粗的图题数
- `chk_capdup.py`：图题重复、同图号多标题
- `chk_boldpara.py`：整段（含 `。`、len>60）被加粗的行

实测：无图题图片组 **81 组 / 124 张 → 24 组 / 39 张 → 9 组**（剩下的多是「资料来源」独占页与「八个重要变量」整页图组，
图标题烘在图内、OCR 没读出来，**不要自己编标题**）。

**交付纪律**：本轮改完 `extract.py`（caption 排序）后没有重跑 extract，`/tmp` 里仍是旧版——报告时必须写明哪个 md5 是旧版、缺哪些修复，

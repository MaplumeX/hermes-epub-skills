# M7 结构与噪声（页眉、边注、标题层级）

> **什么时候读**：页眉/页脚/边注混进正文、章节标题被误删、标题层级与子标题判错时。
>
> **相关脚本**：`scripts/diag_two_note_systems.py`

> 本篇内容自 SKILL.md 拆出，条目逐字保留（含实测数字与原节出处）。

## 来自「教科书（MathML 公式 + HTML 表格 + 页面圈码脚注 + 缺失插图）」

- **章名取众数 + 归一化比较**：同一章各页页脚章名空格/OCR 差异（`第11章 总需求I：…` vs `第 11 章 总需求 I：…`）会让 `(章号, 章名)` 元组判成两章、重复出 `# 标题`；改为按章号取章名众数，比较时 `re.sub(r'[\s：:·]', '', s)`
- **篇分隔页 = 全图页 + 页眉「第N篇」+ 竖排标题块**：只有 1–4 个块（竖排篇名 text + `第N篇` title），页眉可能只有 `第1篇`；不能只认页眉，也不能当正文输出
- **页脚噪声正则族（教科书）**：`宏观经济学（第十版）`、`\d{1,3}\. 宏观经济学（第十版）`、`第\s*\d+\s*章[^，。；：？！]{0,32}`、`目录 3`、`《经济科学译丛》总序 1`；**页眉里混入的正文续句**（`于国外产品变得较便宜了。`、`方面提供了见解。`）要按「含句读 + len>8」救回正文，不能一律丢
- **章节归属兜底：小节号优先于页脚**：页脚偶尔漏识别会把下一章首节算进上一章（曼昆 14.1 被算进第13章、13 章因此多出 9 个二级标题）。规则：见到 `^\d+\.\d+` 的 `##` 小节标题时，若小节号整数部分 ≠ 当前章、且该章号在章名表里，就**先补发 `# 第N章 章名`** 再输出小节标题（配 `emitted` 集合防重复）
- **页脚章名的特殊章**：`总序/序言/辅助材料和媒介/术语表/译后记/结束语` 也常只在页脚出现（如 `《经济科学译丛》总序 1`、`术语表`、`卢远瞩`）。按 `startswith` 逐个匹配（总序用 `in`，因为前面带书名号），匹配到就把该章名当 chapter 键；否则整段会挂在上一章末尾
- **标题层级必须按原书结构：篇 → 章 → 节（用户会直接指出「章不是应该在篇下吗」）**：`#` = 篇 / 前置章节，`##` = 篇下的章，`###` = `x.y` 小节，`####` = 小节内的案例研究/参考资料/小标题。**不要把篇和章并列成同级 `#`**——即便每章独立拆 xhtml（`--epub-chapter-level=2`）也一样要降级；用户看的是导航树，不是文件切分。
  - 层级：`ch_level = 2 if (cur_part and isinstance(ch, int)) else 1`；无篇的 front matter 章（总序/序言/辅助材料和媒介/结束语/术语表/译后记）保持 `#`，其小节降到 `##`（`off = 2 if isinstance(cur_chapter, int) else 1`，`heading(ch_level + off, …)`）。
  - **陷阱：`ch` 取自本页页脚，页脚漏识别时 `chapter_no is None` → `ch_level` 退回 1，同一章里 h1/h2 混排**（本会话改完第一次仍不对，症状是 `1.3 本书的安排` 变成 `##` 而 `1.1` 是 `###`）。必须用 `eff_ch = ch if ch is not None else cur_chapter` 算层级。
  - 特殊小节：结束语里的「启示 2/3」降到 h3（挂在「四个启示」下）；「宏观经济学的八个重要变量」是独立附录级内容 → `#`。
  - pandoc：三层导航用 `--toc-depth=3 --epub-chapter-level=2`（篇→章→节）；`--toc-depth=2` 只出两层。生成后 **`grep '^#\{1,2\} '` 打印层级树自查**，别只看 TOC 条数（条数对但嵌套错是常态）。

## 来自「中译本学术专著·双注释体系（页脚圈码 + 章末「译注」数字） / 收尾阶段实测（第二…」

- **索引的双栏缩进不可还原，如实交付**：主题索引/人名索引原书是双栏 + 子条目缩进，OCR 把双栏拉平后 `x0` 在交错行里不可靠（同一页 `x0` 在 36/59/68/73 之间跳），按 `x0` 分层会造出假层级。做法：统一输出 `- 条目` 不分层，并在交付说明里写明「文字一条不少，层级缩进无法还原」。

## 来自「学术专著（全书 MathML + HTML 表格 + 页脚圈码脚注 + 图目录/索引…」

- **章节层级（中译本三档）**：`第X章` → `#`；`第X节` → `##`；`一/二/三 + 空格 + 短标题` → `###`（**排除字符集里不要放全角冒号**，`四 均衡增长路径：数量体系` 含 `：` 会漏判）；附录 `B.N` → `##`（挂在 `# 附录B` 下）。**正文行首「第一章主要明确…」不是标题**——靠 `len<40` + 无 `。！？，、；` 挡住
- **页眉噪声两种形态**：① title 块重复书名（去空白后 == 书名，本案例 p11/p29/p57/p119 四处）→ 丢；② header 里 `......`、`• • • •` 装饰行 → 忽略。`[Unreadable]` 也要滤
- **`Ground Truth` 噪声出现在 preproc text（不只是 discarded）**：`The Ground Truth image displays a single, solid horizontal line…` 整段 650 字，混进正文会毁掉索引区。过滤判据：含 `Ground Truth image displays` 或 `quick brown fox`

## 来自「中译本学术专著（页脚圈码脚注 + MathML 公式 + HTML 表格 + 少量插…」

- **页脚注释排序按 `(y, x0)`**：同一 y 并排的 ①② 只按 y 排会得到 `notes [2,1]`——诊断信号就是「body `[1,2]` vs notes `[2,1]`」（本案例 3 页）
- **标题去空格后归一化**：`第一章马克思的方法` → `第一章 马克思的方法`；`附录一关于再生产表式问题` → `附录一 关于…`（正则必须含 `附录[一二]`，只写 `第[一…]+[章篇]` 会漏）
- **附录下的「一、二、三」降一级为 `##`**（附录本身是 `#`）；篇标题用汉字数字 `# 第一篇 …`（`'一二三四五六七八九十'[n-1]`），别输出 `# 第1篇`

## 来自「中译本教科书·多分册（圈码页脚注按**章**连续编号 + 答案/术语表双栏 + 图组…」

- **中文之间的 OCR 空格要归一**：`(?<=[汉字])\s+(?=[汉字])` → 删、`第 3 章`→`第3章`、`第 11 版`→`第11版`。不归一则 `^第\s*(\d+)\s*章` 之外的层级正则（`^\d+\.\d+\s`、`^[A-Z]$`）会静默失配，标题被降级成加粗段落
- **`discarded header` 里恰好等于标准小节名的块必须救回为 title**：OCR 常把章末小节标题判成页眉（`header` 块内容就是 `推荐阅读材料`、`小结`），按「header 一律丢」会静默丢掉整节标题——本案例 4 处（第2/4/16/19章的「小结」「推荐阅读材料」）直到数导航条目才发现。判据：`re.sub(r'\s','',text) in {'小结','本章小结','练习题','分析问题','推荐阅读材料','定义'}` → 按 y 插回 blocks 当 title。**成品验收信号**：`grep -c '^### 小结'` 应等于章数（本案例 19 章 → 19 个）
- **`discarded footer` 里的成句中文是正文引导句**：`含汉字 + len>15 + 以 。！？ 结尾` → 救回 blocks（本案例 B p135 页末「我们现在使用数学方法对这些概念做更精密准确的分析。」被整句丢在 footer）
- **空页说明文字也是噪声**：`The OCR result should be empty, as the image contains only…`（与 `Ground Truth image displays`、`quick brown fox` 同类）会整段混进正文，加进 NOISE_RE

## 来自「中译本教科书·单册拆多文件（`title` 自带 level + 图题被拆散 + 书…」

- **`title` 块有 `level` 就别自己猜层级**：level 1 → `#`（编、章、章附录、前置章节、术语表/索引/译后记），level 2 → `###`（小节），`####` 只留给章末区内部的小标题。**篇和章都是 level 1，但导航树要「编 → 章」两层** → 章降到 `##`，篇保持 `#`
- **页码偏移用众数**：`offset = mode(index - pageno)`（本例 758 页一致为 42），TOC 页码 + offset 直接得 pages.json 索引，比逐页找标题可靠得多
- **术语表词条不是都在 `title` 块**：`text` 块首行常是「英文词条 + 中文译名」整行 → 首行加粗、其余作释义。索引的子条目（小写开头，如 `balance sheet 资产负债表，158~161`）用全角空格缩进、**不加粗**；字母（`A`/`B`）只加粗、绝不能给 `##`
- **小节标题对齐 TOC 的四招**（本例 876 条目录 vs 正文只识别 810 条 → 补到 876）：
  1. **精确匹配要在整个剩余区间里找**（`for j in range(i, len(secs))`），只扫 `i..i+8` 会漏掉被前面块跳过的节
  2. **前缀匹配**：正文只印 `补充读物`、目录写 `补充读物和互联网站` → `sn.startswith(tn) and len(sn)-len(tn)<=6`；匹配上后**输出目录的完整标题**，不要输出正文的残缺标题
  3. **章末兜底插入**：章内 TOC 有、块流里一个都没命中的小节，按 `page_start[页码+offset]` 在对应页开头插 `### 标题`（`page_start[pi] = len(out)` 在进入每页时记）。**插入位置必须落在同页已输出标题之后**：同一页常「既有命中的节、又有要补的节」（本例 `价格指数` 命中、`总结提要` 未命中），一律插页首会把「总结提要」排到「国民账户简评」前面 → 记 `page_heads[pi].append((sec_idx, out_idx))`，插入点取 `max(out_idx for h in page_heads[pi] if h[0] < sec_idx) + 3`
  4. 被拆成两块的标题要拼起来再比对：`tn+nxt`、`tn+'和'+nxt`、`tn+'与'+nxt`
- **章末区名字必须精确匹配，不能用模糊匹配**：`反托拉斯法与效率` 与 `反托拉斯法与经济学` 相似度 >0.82，模糊匹配会把真小节吞掉 → 进入章末区后 `match_section(..., exact_only=True)`
- **概念复习的块内多行是列表**：`text` 块内 `\n` 拆行，全部 <26 字且都不以 `。` 结尾 → `- ` 列表；否则按「汉字接汉字不加空格、其余加空格」拼回整段（OCR 把一句拆两行是常态，不拼就成两段碎句）
- **署名/题词被拆成列表项**：`——弗兰克·奈特` / `(Frank Knight)` / `《风险、不确定性和利润》(1921年)` 三块被当 `- ` 列表（判据「全部 <26 字且都不以句号结尾」误命中）。规则：`segs` 里出现以 `——` 开头的行 → 合成一条斜体署名 `*——作者 书名(年份)*`；纯条目列表的判定门槛从 `len(segs) > 1` 提到 `>= 3`
- **问题讨论的选项粘连**（`a. … b. … c. …` 挤成一段）：正则 `(?<=[汉字。？！；：、）)"])\s*([a-f])\s*[.、]\s*(?=[汉字A-Za-z])` 命中 ≥2 次即拆段，`split()` 交替取「字母 / 文本」。**字母类必须含到 `f`**——`e.` 后面还有 `f.`，只写 `[a-e]` 会漏最后一个选项

## 来自「陷阱」

- **页码边注两种形式**：独立块（extract 阶段丢弃）与**内嵌正文** `[226]` `[227]`（第二部分 76 处）——后者需 `re.sub(r'\[\d{2,4}\]', '', t)` 清除
- **章节子标题层级体系（用户要求校对）**：A. B. C. → `##`（第二层）、a. b. c. → `###`（第三层）、α)β)γ)δ) → `####`（第四层，与第一部分 `#### a. 存在(Sein)` 一致）。注意：第一部分存在论/量 部分 a. b. c. 用 `####`（因 A. 质 是 ### 层级），第二部分用 `###`——层级取决于其上级标题
- **a. b. c. / α)β)γ) 行双义性（标题 vs 正文）**：layout 中这些开头的行可能是章节子标题（"α) 同一性 (Identität)"、"β) 反映推论(Reflexionsschluß)"、"a. 严格意义上的概念(Der Begriff als solcher)"），也可能是 § 正文（"γ) 内核是根据…" 实为 §138 正文，对应德文 c) Das Innere ist der Grund…；"β) 现实东西…" 为 §144 正文，德文 b) Das Wirkliche aber…）。判定三步：① 下一非空行是否为 § 标题 ② 行长 <60 ③ 对照德文原文（德文 a./b./c. 开头且内容长 = 正文；独立成行 = 标题）。实现：render 中 para+body 类型、len<60、且下一 paras 项是 section → a. b. c. 输出 `### {t}`、α)β)γ) 输出 `#### {t}`
- **α)β)γ) 行"搭便车"陷阱（本会话教训）**：layout 中 α)β)γ) 子标题多为 type='text'（非 title），且常紧跟附释引用块——类型状态机把它们并入引用块末尾，渲染成 `> ` 格式，看似"已正确标记"实为偶然副作用。用户问"为什么用 >"后确认正确格式是 `####`。修复：merge_main 中在 CITE_OPEN 分支后加规则——`re.match(r'^[αβγδε]\)\s*\S', t) and len(t) < 60` 的行 flush 当前引用块、ctype 重置为 'body'、独立成段；render 再按标题规则输出。**教训：不要轻信"已正确标记"的格式，先查它在数据流中的来源（type 属性 + 是否被状态机吞并）**
- **heading_level 陷阱**：layout type='title' 的 α)β)γ) 行（如 β) 反映判断）会被 heading_level 的 `a. b. c. α) β) γ)` 规则误判为 ###——从 heading_level 移除 α)β)γ)，统一走 render 的 #### 分支
- **§ 标题层级（用户确认）**：`**§ N**` 保持加粗段落格式（模拟原书黑体），不进 EPUB 目录（`--toc --toc-depth=3` 只收录 `#` 标题层级）；用户否决了改为 `#####` 标题的方案——勿再改成标题层级

## 来自「中译本教科书·单册拆多文件（`title` 自带 level + 图题被拆散 + 书…」

- **TOC 小节标题补齐三招**（正文 810 条 vs 目录 876 条）：① 精确匹配要在**整个剩余区间**里找，只在前 8 个里找会漏（前面有块被跳过时）；② 前缀匹配救「补充读物」→「补充读物和互联网站」（`sn.startswith(tn) and len(sn)-len(tn)<=6`）；③ 章末按 TOC 页码把仍缺的标题插到**同页已输出标题之后**（`max(h[1] for h in page_heads[pidx] if h[0]<k) + 3`），不能一律插页首（会把「总结提要」插到「国民账户简评」前面）
- **概念复习/关键术语的短行列表判定用「≥3 行且每行 < 26 字且无句号」**，写成 ≥2 行会把两行正文误拆成列表
- **卷首题词 `——作者` + 书名/年份分成 2–3 个块**：按「含 `——` 开头」合成一条斜体署名，不要渲染成 `- ` 列表

- **竖排书名页眉会落进 `preproc text`**（本书 15 处，症状：正文里凭空出现一行「资本的限度」）：判据 `bb[2]-bb[0] < 45` 且去空白后恰等于书名 → 剔除。`aside_text`/`header` 里的同名噪声已过滤，但这一路是**正文块类型**，最容易漏（本书 grep `^资本的限度$` book.md 从 15 降到 0）。

## 来自「逐节讲解+注释（圈码脚注，每节重新编号）」

- **节标题可能是 text 类型**（第84节案例），判定不能只看 block type，须正则 + 行长校验（`^第\s*\d+节$` 且 len<24）
- 流构建注意：**页眉去重**——章名页眉会以 title 块重复出现（"第三篇\n概念论" 多行页眉、正文句以章名开头如"第一版序言接着谈到……"），需 seen_chapters 去重 + 精确匹配章名而非前缀
- **text 类型子标题识别需前瞻**：`B. 量(Die Quantität)`、`(b) 定量(Quantum)`、`(c) 程度(Grad)`、`(b) 实存(Die Existenz)` 等子标题是 text 类型（非 title）。判定：text + len<40 + 无正文标点 `[,，。;；:：]` + **下一块（按 y 排序）是节标题或 title 类型子标题**。extract.py 必须保留每块 y 坐标（index 字段在 extract 时丢失，前瞻只能按 y 比较）
- **章节标题检查必须在 helper 过滤之前**：`导言`、`逻辑学概念的初步规定` 等章节名同时出现在 HELPER_RE 噪声模式里（`导言\s*$`），若先过 helper 过滤会误杀章节标题——顺序：章节标题匹配 → helper 过滤 → 其余
- **篇名德文副标题**：`(Die Lehre vom Sein/Wesen/Begriff)` 是 title 类型，直接 emit 为普通段落（不设标题层级），否则会污染 TOC

## 来自「中译本学术专著·双注释体系（页脚圈码 + 章末「译注」数字）」

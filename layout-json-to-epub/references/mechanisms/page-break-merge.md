# M2 跨页断句合并

> **什么时候读**：正文出现「页末半句 + 下页半句」被切成两段；或改动了任何合并逻辑之后。**这是最高频的假性丢字。**
>
> **相关脚本**：`scripts/merge_page_breaks.py`、`scripts/check_loss_blocks.py`

> 本篇内容自 SKILL.md 拆出，条目逐字保留（含实测数字与原节出处）。

## 来自「教科书（MathML 公式 + HTML 表格 + 页面圈码脚注 + 缺失插图）」

- **段落合并只能在页边界做**：`mergeable=first_in_page`，只让每页**第一块**与上一页末尾尝试拼接；页内各块本就是独立段落，按「前块无终止标点」合并会把相邻两段粘成一段（本会话第一版 3750 段 vs 修正后 4072 段，差的全是被粘掉的段落）

## 来自「尾注（附注）制 + 跨册合订（本册无注释文本）」

- **跨册合订**：先按 `^\[\^id\]:` 把每册的**脚注定义区切开**，正文区再做「末段无终止标点 → 与下册首段拼接」；下册缺编名页则在 `## 第N章` 前补 `# 第二编 …`。**下册若丢了某个章节标题（OCR 只留副题行），必须按上册目录补齐**——不补则该章正文被算进上一章，整章尾注链接错位（症状：上一章链接数 > 附注数、该章 0 链接）。

## 来自「中译本学术专著（页脚圈码脚注 + MathML 公式 + HTML 表格 + 少量插…」

- **TERMINAL 必须含全角冒号 `：`**：以「如下面所示：」「……他说：」结尾的引导句是完整段落，不含冒号会把下一段引文粘上来（本案例 within-page 非终止对 361 → 48）
- **短前块（<20 字且不以 `，、：` 结尾）不参与跨页合并**：「一、引言」「还有：」「保罗·M. 斯威齐」这类结构/署名块不能被后段吞掉

## 来自「中译本教科书·多分册（圈码页脚注按**章**连续编号 + 答案/术语表双栏 + 图组…」

- **圈码页脚注是「按章连续」而非「每页从①重编」**：与斯威齐案例相反。判定方法：逐页打印 `body marks` 序列 vs `notes` 序列，跨页看是否递增（本案例 第1章 ①-⑦ 跨 p19-31，第2章 ①-⑲ 跨 p35-70）。**先做这个判定再写 build**，判错会导致整章脚注全错位
- **双栏判定只用「左右块数」，且不要加「跨栏块数量」限制**：左 = `x1<=445 and x0<250`，右 = `x0>=340`，`len(left)>=2 and len(right)>=2` 即双栏。加 `len(full)<=2`（跨栏块少）会把「小结 / 推荐阅读材料」这类**双栏夹整段跨栏导语**的页判成单栏，整节内容按 y 交错串栏（症状：小结要点乱序、文献条目与中文说明错位）。**右栏阈值取大了会吃掉答案区右栏**：本案例先写 392，右栏题号 `x0=395` 被划进左栏，题号与解答错配（`2.2` 后面跟 `1.1` 的答案）；改 340 才对。判定后给每块打 `_col` 标记，供跨页续段用
- **双栏排序：跨栏块切段，段内左→右**，并给每块打 `_col` 栏位标记。跨页续段条件写成 `prev_open and (not first_prose_done or col_changed)`——只看「本页首块」会把右栏首块误接到左栏末段（症状：答案区题号与解答错配、`2.2` 后面跟着 `1.1` 的答案）
- **图面积过滤不能一律 `area>300000` 丢弃**：单幅大图会被误杀（本案例 图 5.8 补偿性差异 area=350196 被丢，症状是图号连续性检查报「图5 缺 8」）。改用「**宽度>650 或 area>450000**」判整页/跨页宽图；`图 2.4` 整组在源数据里根本没有图块（正文仍在引用），只能插〔图〕占位并写进缺图清单

## 来自「中译本教科书·单册拆多文件（`title` 自带 level + 图题被拆散 + 书…」

- **`extract.py` 合并页脚注时必须保留 `y`/`x0`**：合并后只留 `{'text': …}`，后面按 y 就近挂载题注时 `KeyError: 'y'`。写成 `{'text': t, 'y': n['y'], 'x0': n['x0']}`
- **跨页合并加「本页底部有图就不合并下页首块」这条会误伤**（本会话实测：修好 图27-6/图30-9 的题注，同时把 图29-7 的题注和图29-9 的图释打散，最终没收敛）。要判就判「下页首块本身是不是题注/图释」（以图号或短标题开头），不要判本页有没有图；没把握就别加这条，改为对个别页白名单处理

## 来自「中译本教科书·单册拆多文件（`title` 自带 level + 图题被拆散 + 书…」

- **题注被挂到下一章「小结」框的续文位置**（图22-11）：`fig.cap` 里装的其实是上一页「小结」段落的尾巴——用「上页末块结尾正是这段的开头」验证后拼回正文，题注另从被误判成 `####` 的 title 块取
- **页脚注合并后必须保留 y/x0**：`merged.append({'text': t, 'y': n['y'], 'x0': n['x0']})`。只存 text 会让后续「按 y 挂到最近图块」直接 KeyError
- **跨页合并排除「下页首块是题注/图释」的规则不能写太宽**：`本页底部 y>380 有 fig/table 且下页首块以汉字开头就不合并` 会误伤正常续段（本案例因此丢过 图29-7/图29-9 的题注，需要回退重跑）。宁可用「下页首块长度 < 200 且本页底部图块 y > 380」并逐条核对

## 来自「陷阱」

- **TERMINAL 正则必须整条锚定在句末（`$` 只加在最后一个分支上＝没锚定）**：写成 `r'[。！？…]|\.["”]?$'` 时第一个分支没有 `$`，`re.search` 会匹配段中任意位置——于是任何**句中含 `…`** 的段落都被判为「已结束」，跨页断行整段不合并（本次症状：总序首段 `…教育事业的快速` + 下一页 `发展，国内…` 没接上，且不报错）。正确写法把两个分支包进一个组：`r'([。！？…”』」）)\]\】：；]|[.!?])["”’』」）)\]]*$'`。**改完用 3 行断言自测**（`ends_terminal('…快速')` 必须 False）。
- **诗行（引诗）分组**：同页/跨页连续的短块（≤34 字且含中文标点）合并为一段、行间用 `<br/>`；跨页要按**节点流**分组而不是按页（否则一首诗被页边界切成两段）。**小标题判定要把「以 `……`/`——` 结尾的行」排除，但不能整体排除 `—`/`·`**——否则 `“堪萨斯—内布拉斯加法案”`、`德雷德·斯科特案件的判决` 这类小标题会被降级成正文（实测踩过）。
- **OCR 误分类**：脚注跨页续文可能被误放正文区（p22/p27 案例）——正文出现"以半句开头、与脚注尾部衔接"的块时警惕；用户可能提供权威文本，用其重建脚注
- **块序可能未按 y 坐标排序**：layout.json 个别页的正文块顺序错乱（§ 标题 y 坐标小于正文块却排在其后）——处理每页块前先 `sorted(p['body'], key=lambda b: b['y'])`，否则跨页句子被拆断且归属错误（p165 §87 案例："…而当它同"归入 §86 附释、"样被看作…"跑到 §87 后；p65 §20 同类问题）
- **终止符字符类里不要放引号/括号（本会话实测）**：把 `”』」）` 也算作终止符时，以「…还远远早于"冷战"」结尾的段落被判为已结束，下一页的「的结束、原共产主义经济体的…」整段不合并，且不报错。**终止符只认句末标点**：`([。！？…；：!?])[”’』」）)\]]*$`——引号括号只允许作为**尾随字符**，本身不算终止（与下面「必须含全角括号」那条并存：括号出现在句末标点之后才是正常收尾）

## 来自「跨页/跨块重复行（OCR 页眉页脚式重复）」

- **现象**：原书排版跨页重复行被 OCR 两次识别（p66 案例：块[3] 以 `[293]` 页码开头，内容与前块尾部重叠 32 字："是被动的, 被当作材料而用于事情…"）
- **扫描**：页内相邻块 + 跨页尾块 vs 头块，非空白字符 LCS ≥10 判定（`lcs_len(a,b)` 找 a 尾部 == b 头部 的最长公共前缀）
- **修复**：merge_main 拼接分支先 `_dedup_overlap(prev, t)`——若 t 开头与前文末尾重叠 ≥5 字，截掉重叠部分再拼接
- **顺带修复缺标点**：跨块拼接时前块以汉字结尾 + 后块以 `数字. ` 开头（如"…并且从中显露出来" + "3. α) 活动"）→ 前块补句号"。"（对照德文原文确认句子边界，如 hervorgeht.）
- 扫描工具：块尾/块头 LCS 重叠 ≥10 非空白字符即报告，先扫页内再扫跨页（跨页扫描变量名别写错——cur 未定义/混合 int+list 是常见笔误）

## 来自「中译本学术专著·双注释体系（页脚圈码 + 章末「译注」数字） / 收尾阶段实测（第二…」

- **跨页合并必须能跨越页底注块（本书最高频的假性丢字）**：OCR 输出顺序常是「页末半句 → 该页 page_footnote 块 → 下一页首块」。只判「相邻两块」的合并逻辑会在这里断开，全书 30 余处正文被切成两截（症状：保真度比值卡在 0.98、正文段数偏多，但逐块扫描报「0 丢失」——因为字都在，只是断成两段）。修法：合并时记住「最后一个正文段的下标」`last_p`，遇到 `fn` 块只计数不清零，下一个 `p` 块允许与 `last_p` 拼接；条件仍是「前段无终止标点 + 后段非题注」。

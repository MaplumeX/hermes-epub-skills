# 斯威齐《资本主义发展论》layout.json → EPUB 案例

## 源文件
- 三册 layout.json（同一本书按页连续切分，非分篇）：
  - A `doc_e1f492b7e2ca` 200 页（p0-199，印刷页 1–181）
  - B `doc_1b1ba71f7adc` 200 页（p0-199，印刷页 187–382）
  - C `doc_781c57e2de52` 77 页（p0-76，印刷页 389–458）
- 结构：出版说明 / 中译本前言 / 序 / 第二次印刷本序 / 导言 → 第1–4篇 → 第1–19章 → 一、二、三…节 → 附录一（都留重人，含三小节）/ 附录二（希法亭）→ 译名对照表（三画～十六画）
- 工作目录 `/root/sweezy/`：extract.py → build.py → pandoc → add_metadata.py

## 本案例的坑（与旧案例不同处）

1. **表格的 HTML 在 `table_body` 子块里，不在 table 块自己的 lines 里**。`spans(b)` 直接取会拿到空 → 必须遍历 `b['blocks']` 再取 span 的 `html`。症状：8 张表全部消失（`grep '^+' book.md` 为空）。
2. **表题/表注在 `table_caption` / `table_footnote` 子块**，不在 image 块的 caption 里（只有“表 1 价值计算”这种边栏表题才落在 image_caption）。跨页续表页首块 caption 是“续表”，合并判据用「表头行归一化后相同」（原始字符串会因 `c` vs `$c$` 不同而失败）。
3. **`html_table_to_grid()` 返回二维 list，不是 markdown 字符串**——要再调 `grid_to_md(rows)`。直接 append 会 `TypeError: expected str instance, list found`。
4. **行内公式里的脚注圈码**：`^{①}` 形式的 inline_equation span 必须还原成脚注标记；且**脚注引用不能被包进 `$...$`**。正确顺序：先把 MATH 存成私有标记 `{{MATH:...\ue006`（用私有字符收尾，内容含 `{}` 不能用 `}}` 收尾），再单独跑一遍把 `$...$` 里的 `[^pN-M]` 搬到公式外。若先拼 `$...$` 再用正则找 `$[^$]*[^p...][^$]*$`，会被相邻公式的 `$` 配错（实测把整段正文吞进公式）。
5. **`wrap_math` 的两个必要修正**：
   - 左扩允许 `{`/`}`（否则 `c_{1}` 被切成 `$c_{1$}`）
   - **花括号未配平要继续右扩**，否则 `\frac{消费增长率}{生产资料增长率}` 被切成 `$\frac{消费增长率}${生产资料增长率}`
   - 命中区间重叠时合并而不是丢弃
6. **半角括号要先成对处理**：OCR 常见 `(1946年）`（左半角右全角），逐字符转换只转右半边。做法：`fix_parens()` 找配对 `(...)`，内部或相邻有汉字就整对转全角，然后再跑两遍逐字符转换（第二遍用已转好的括号判断逗号）。
7. **译名对照表是双栏**：按 `x0 < 2500` 分左右栏，块内 `\n` 拆行 → `- ` 列表项；“三画/四画”这类 title 块单独成 `##`。英文名跨行连字符（`Tugan-Baran-\nowsky`）拼接时不要补空格。
8. **插图 5 张**（layout 只给哈希名，图在用户发来的分卷 zip 里）：
   - 第五章「图一 产业过程」`51b5f578…`
   - 附录一「图一」`359045ad…`「图二」`d77fb38c…`「图三」`76b22867…`「图四」`9f2a1f29…`
   - 判定「真插图」用 `area > 400000`（其余 371 个 image 块都是竖排装饰条 160×350 和页脚小图）
   - 分卷 zip 用 `7z x -y -oout images.zip`（保留卷名），**不要 cat 合并后 unzip**
   - 图题在图后输出：`![图X](images/hash.jpg)` + 空行 + `**图X 标题**`
9. **篇分隔页**：单独一页只有 `第一篇` + `价值与剩余价值` 两个 text 块（无 title 类型），`第N篇` 用中文数字输出（`第1篇` → `第一篇`）。
10. **章节标题空格**：layout 里是 `第一章 马克思的方法`，但 OCR 常丢空格；`norm_heading()` 去所有空白后按 `^(第[一二三四五六七八九十]+[章篇]|附录[一二])` 重插一个空格。
11. **附录下的 `一、二、三` 要降级**：`cur_h1.startswith('附录')` 时 `###` → `##`。
12. **`[^pN-M]` 编号用全局页号 gpage**（A:0-199、B:200-399、C:400-476），三册 pi 会撞号。

## 成果
- 472 条页脚圈码脚注，正文标记与条目**逐页 0 不匹配**；pandoc noteref 472 / backlink 472
- 65 处行间公式 + 全部行内公式走 MathML（`--mathml`），253 个 math 元素
- 7 张表（表1/2/3/3甲/3乙/4/4甲），表2 跨页续表已合并
- epubcheck 5.1：0 errors / 0 warnings；内部链接 1128 条无效 0
- 保真度：非空白字符比 1.0007；逐块丢失扫描剩 22 条全为刻意剔除项
- 成品 892 KB（含 5 图 + 封面）

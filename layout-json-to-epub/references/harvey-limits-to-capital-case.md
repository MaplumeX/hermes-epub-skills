## 收尾阶段实测（第二轮：断句合并 / 标记序列 / EPUB 注入）

第一轮结束时的指标是 `unresolved_circ 1 / missing_note 10 / orphan_note 36`，保真度 0.9811；
第二轮把 `missing_note` 降到 0、`orphan_note` 降到 13、`dup_mark` 0，正文段数与字符数回升。

### 1. 夹着页底注的跨页断句（保真度 0.98 的真正原因）

- 症状：逐块丢失扫描报「0 丢失」，但保真度比值只有 0.98、正文段数偏多。根因是字都在，只是**断成两段**。
- 触发形态：`页末半句（无终止标点）` → `该页 page_footnote 块` → `下一页首块（续文）`。
  只判「相邻两块」的合并逻辑在这里断开，全书 30 余处。
- 修法：合并时记 `last_p = 最后一个正文段在 out 里的下标`，遇 `fn` 只 `pending_fn += 1` 不清零，
  下一个 `p` 满足 `(pending_fn > 0 or 跨页) and not ends_terminal(prev)` 就与 `last_p` 拼接。

### 2. 合并后圈码挂错页（unresolved_circ 1 → 31）

- 合并把后页文本并进前页段，段的 `page` 属性若取前页，后页那个 `①` 会去前页脚注表里找。
- 修法：**extract 阶段给每个圈码打来源页戳** `{{MARK:①@A30}}`；build 的 `mrepl2` 拆 `@` 后按
  `(页戳, 圈码)` 查 `fnmap`。`page_footnotes()`、「译注区判 fn」两处正则都要容忍 `(@[A-Z]\d+)?`。

### 3. 页底注里的标记必须单独渲染（`render_fn`）

页底注文本里夹 `①`（交叉引用，如「见第51页注①」）和裸数字（OCR 噪声）。若套用正文的
`render_text`，交叉引用会被当成本页脚注引用，产出 `[^fA30-①]: … {{MARK:12}}` 这种**未渲染 token
混进脚注定义**（`grep -c '{{' book.md` 应恒为 0，是最快的探针）。
`render_fn` 的规则：圈码保持纯文本、`*` 丢弃、数字**只在正文确实无落点时**才建链接（顺带救活
「注释里才有标记」的条目）、其余丢弃。

### 4. 标记序列修复（`^{11}` 读成 `^{1}`）

序列出现 `1,2,3,1,5`、`8,3,10` 这类重复/倒退时，按文档顺序维护 `last`：
`n <= last` 且 `last+1` 在该章译注表 → 改成 `last+1`；`n == last` 且无对应条目 → 删掉该重复标记。
本书跑完 `dup_mark` 4 → 0。

### 5. 上标被读成普通数字（4 处，本轮新增形态）

形态：句末引号后紧跟数字再接括注引证。
- `…才是生产力发展的界限”10（《资本论》第3卷，第484页）` → 第3章注10
- `…携手并进的。”39（《资本论》第1卷，第604页）` → 第4章注39
- `…才同时具有资本职能的意义”15（《资本论》第2卷，第77、81页）` → 第9章注15
- `…资本主义生产就根本完结了。”81（《剩余价值理论》第2册，第43—44页）` → 第11章注81

扫描正则 `(\d{1,3})(（《[^）]*》第[\d、—]+页）)` 或 `([”’])(\d{1,3})(?=[（(《])`，命中后逐处人眼核对，
再写进 `TEXT_FIXES` 表。通用正则自动替换会误伤 `16、17世纪`、`第77、81页`。

### 6. 源数据整页缺注释 → 占位条目（第3章 65–73）

源数据 A p190 只有两块（`64.《全集》第30卷…` 与 `74.《全集》第30卷…`），65–73 整页未录入。
做法：`ch['lost'] = 正文用到但译注表缺的编号` → 按连续区间合并成
`〔源数据缺该条注释：注65—73（共 9 条）在源文件中未被 OCR 录入〕`（同区间后续条目写「同上」），
照样建 `id`/`↩`。正文上标可点、读者知道为什么没有内容。

### 7. 表 8.1 重建

- 源 HTML：`<tr><td rowspan="2">物质形式</td><td colspan="2">生产内部的范畴</td></tr>` + 一行把
  「厂房和设备…／硬原材料…／劳动力」三行并成一格。
- `html_table_to_grid` 展开 `rowspan` 后首列重复（两行都是「物质形式」）。正确改写是

### 11. 引文块（第三轮：单段 → 多段）

用户口径：「文段结尾有标注出处且独立成段」→ 转引用格式；随后补一句「**也有可能是多段的**」。

- 段末带出处的段落共 **77** 个，其中只有 **57** 个是整段引文。排除的两类：**100 个作者分析段**
  （例「《资本论》开篇的论述简单得异乎寻常。马克思把商品界定为…（《资本论》第1卷，第38页）」）、
  **20 个段末引语**（例「马克思接着补充了一个颇为隐秘的说法：“成为生产工人不是一种幸福，而是一种不幸。”……」）。
  只按「段末有出处」跑正则会误伤 120 处。
- 判定方式：`scripts/check_quote_paragraphs.py` 导出全部候选（含章、是否含引号、前一段末尾）→ **逐条读原文**
  分类 → 把整段引文的**段首 15–20 字指纹**写成 `QUOTE_STARTS` 常量，build 时去空白去标记后 `startswith` 比对。
  指纹比正则可审计，判错改一行。
- 多段：55 个引用块，其中 **3 个多段块**——第2章「所以，让我们回到马克思的论述…」（4 段，至《大纲》第297页）、

  （2 段，至《资本论》第1卷 765）。前两段以「……」或断句未了结尾，是被页边界+OCR 切开的同一段引文。
- 误并两处（已切回正文）：`希法亭…希法亭说（列宁也赞同这一点）：金融资本` 与 `…正如布洛维所说的那样，他讨论了`

### 13. 第三轮作废（用户：「v3错了 撤回」）

v3 的「向前回溯把引文前未结句的段落并入引用块」被用户否决：它吞进作者引导句
「所以，让我们回到马克思的论述。他说过，抽象劳动」、引导句「希法亭说（列宁也赞同这一点）：」、
并把残片「“这里」单独切成一个引用块。整版作废，回滚到 57 块全单段（`v3回滚`）。
**结论：这类语义归属判断不能靠规则，加多少判据都拦不住断在半句的引导句。**

## 图题/表题的真实病灶（本轮核心）

第一轮只查了 `chart_caption`，得出「11 个图号缺题注，是 OCR 整行丢失」的结论。
用户回了一句「可能有些图题被当脚注了」——**这个方向是对的，实际只有 1 个真丢失**。

逐块翻 `discarded_blocks` 后找到 8 类位置错误：

| 病灶 | 案例 | 修法 |
|---|---|---|
| 图题整条在 `page_footnote` | 图9-3、图9-4 | 按「图号后不接引用动词」判题注，挂到同页最近图块 |
| 图题在 `chart_footnote` | 图30-10 | 从 fnote 首行拆出标题 |
| 表题在 `page_footnote` | 表16-1/19-2/19A-1/26-2/27-4/28-2/30-2 | 同上，挂到最近表格 |
| 题注挂在相邻 **table** 的 cap 上 | 图5A-1、图5A-3、图18-1 | 从 table.cap 移到 fig.cap |
| 图号 + 标题分在两个 title 块 | 图1A-4（「图1A-4」+「坡度不等于斜率」） | 合并成一条题注 |
| 题注与图释粘在同一 text 块 | 图13-4、图18-8、图20-2 | 按锚点/换行拆 cap + fnote |
| 题注被当成 `####` 小标题 | 图28-6、图22-11 | 标题块降为题注 |
| 题注/图释粘进上一段正文 | 图29-7（句中）、图29-9（图释）、图27-6（跨页合并后） | 按锚点切出，正文复原 |

**判定「是题注还是交叉引用」**：图号后面接 描述/表明/显示/说明/演示/解释/估算/展示/运用/
提供/简要/仅/表示/所/中/到/和/与/及/的/给出/描绘/呈现/列出/告诉我们/清楚/概括/总结/
以/第/为/对/在/有/把/被/从/由/至/（/、/，→ 正文交叉引用；否则题注。
再加一道「第一句到第一个句号 ≤ 60 字」兜底。

**注意别把真注释误判成题注**：`图21-1所示的支出模式被称为「恩格尔定律」…` 是真脚注，
`表 19A-1 所列的是本章讨论所涉及到的主要的宏观经济数据…` 也是。
「所示」「所列」必须在引用动词表里。
